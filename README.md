# Life OS для Obsidian

Единый дашборд для управления жизнью внутри Obsidian: задачи дня, проекты, привычки, финансы, сон, работа, уровни и XP, картотека людей, входящие идеи, а также списки аниме и фильмов с синхронизацией. Плагин работает как **надстройка** над популярными плагинами (Calendar, Tasks, Templater, ICS и др.) и не заменяет их.

> **Статус: ранняя версия (0.1.5).** Плагин проверялся только на синтаксис, в живом Obsidian его ещё мало тестировали. Возможны баги, о которых лучше сообщать через [Issues](../../issues).

## Возможности

**Дашборд («Единый холст»)**
- Уровень и XP, серия дней подряд
- Задачи на сегодня с чекбоксами, главная задача дня
- Проекты (работа, учёба, исследование) со сменой статуса прямо на дашборде
- Месячная сетка привычек, клик по клетке отмечает привычку
- Финансы за месяц (доход, расход, баланс) и график расходов
- Средний сон, часы работы за неделю
- Радар баланса по шести сферам за 30 дней
- Ближайшие встречи и дни рождения, цели, входящие идеи, список «Посмотреть позже»
- Зум и перемещение: `Ctrl` + колесо, `Ctrl` + правая кнопка мыши с движением, перетаскивание левой кнопкой, двойной клик по фону вмещает холст

**Рутина**
- **План дня**: главная задача, список задач, события из Google Календаря (ICS), ближайшие дедлайны, дни рождения и встречи
- **Итоги дня**: рефлексия и отметка привычек
- Шаблоны: встреча, человек (картотека), проект, путешествие; для любого можно подключить свой шаблон Templater

**Идеи**: галерея карточек (по дате или по имени, поиск, вкладки «Входящие» и «Обработанные»). Идею можно создать с названием, текстом, заглавной картинкой и любыми файлами (видео, PDF, аудио, изображения): превью берётся из обложки, картинки или первого кадра видео. Под каждой карточкой поле комментария, выпадающий список «Фасовать…» (в заметку, в проект работы, учёбы или исследования, в «Посмотреть позже», в архив) и кнопки открытия файла, правки и удаления. Файлы копируются в `LifeOS/Ideas/Files/`. Идеи из Telegram попадают туда же.

**Ежедневная зарядка**: набор упражнений без инвентаря (разминка, основная часть, растяжка) с отметками, прогрессом дня и историей за 14 дней. Набор можно менять: добавлять и удалять упражнения.

**Спорт**: вес, целевой вес, прогресс и график, прогноз по времени, ИМТ (если указан рост) и предупреждение о слишком низкой цели. Рекомендованный план на неделю собирается из инвентаря, который ты отметил (гантели, гиря, турник, штанга, резинки, скакалка, зал и др.). Тренировки записываются и идут в XP и радар.

**Telegram-бот** для быстрого ввода: сон, работа, доходы, расходы, активность, вес, привычки, идеи, «посмотреть позже»

**Аниме и фильмы**: у аниме вкладки по статусам Shikimori (запланировано, смотрю, пересматриваю, просмотрено, отложено, брошено), у фильмов и сериалов восемь категорий как на CUB (закладки, нравится, позже, смотрю, просмотрено, запланировано, продолжение, брошено) в виде карточек со счётчиками. У каждой записи обложка, оценка, серия. Аниме синхронизируются с Shikimori, фильмы и сериалы с CUB.
- Ручное добавление и правка любой записи: название, оригинальное название, статус, оценка, серия, год, тип, жанры, афиша (ссылка или файл с компьютера), заметка. Правки синхронизированных записей не затираются при следующей синхронизации.
- **Экспорт и импорт JSON** для обоих списков. Экспорт сохраняет файл в `LifeOS/Data/` и копирует JSON в буфер обмена. Импорт принимает собственный формат плагина, экспорт списка Shikimori, ответ API Shikimori и закладки CUB; можно объединить с текущим списком или заменить его.

## Установка

### Вариант 1: через BRAT (проще всего, с автообновлением)
1. Установи плагин **BRAT** из каталога сторонних плагинов Obsidian.
2. Команда `BRAT: Add a beta plugin for testing` и вставь адрес репозитория: `https://github.com/Qpera/life-os-for-Obsidian-plagin`.
3. Включи **Life OS** в настройках сторонних плагинов.

### Вариант 2: вручную
1. Скачай `main.js`, `manifest.json` и `styles.css` из [последнего релиза](../../releases/latest).
2. Создай папку `<хранилище>/.obsidian/plugins/life-os/` и положи туда эти три файла.
   Папка `.obsidian` скрытая: в Windows включи «Скрытые элементы», в macOS нажми `Cmd+Shift+.`, в Linux `Ctrl+H`.
3. Перезапусти Obsidian, открой Настройки → Сторонние плагины, выключи безопасный режим и включи **Life OS**.

## Быстрый старт
1. Нажми иконку дашборда на левой панели или `Ctrl/Cmd+P` → «Life OS: Открыть дашборд».
2. В настройках плагина укажи свои привычки.
3. Рекомендуется в ядре «Ежедневные заметки» задать папку `LifeOS/Daily`, чтобы Calendar и плагин работали с одними файлами.
4. По желанию подключи интеграции (ниже).

## Настройка интеграций

### Telegram-бот
1. Создай бота у [@BotFather](https://t.me/BotFather) и скопируй токен в настройки плагина.
2. Напиши боту `/start`, он ответит твоим chat id. Вставь его в настройки.
3. Команды:

| Команда | Что делает |
|---|---|
| `/sleep 7.5` | сон, часы |
| `/work 2` | работа, часы |
| `/income 5000 зарплата` | доход |
| `/expense 300 еда` | расход |
| `/act бег 30` | активность, минуты |
| `/habit чтение` | отметить привычку сегодня |
| `/weight 82.5` | записать вес, кг |
| `/idea текст` | идея во входящие |
| `/later название` | в «Посмотреть позже» |
| `/today` | задачи на сегодня |

Любой текст без команды сохраняется как идея. Плагин опрашивает бота раз в минуту, пока Obsidian открыт; накопленное подтягивается при запуске.

### Календарь (ICS)
Google Календарь → настройки календаря → «Секретный адрес в формате iCal». Вставь ссылку в настройки плагина. Повторяющиеся события пока не разворачиваются.

### Shikimori
Укажи свой ник в настройках и запусти команду «Синхронизировать Shikimori» (или кнопку на вкладке «Аниме»). Данные только читаются, обратно ничего не записывается.

### CUB
В настройках плагина введи 6-значный код со страницы добавления устройства на сайте CUB (cub.black/add) и нажми «Войти»: токен и профиль подставятся сами. Адрес API плагин подбирает сам (cub.black, затем cub.rip). Формат ответа API проверен не полностью: если синхронизация не находит данные, поправь «Путь запроса закладок» в настройках (категории фильмов повторяют CUB: закладки, нравится, позже, смотрю, просмотрено, запланировано, продолжение, брошено). Запасные варианты: ручное добавление и импорт из JSON.

## Как устроены данные

| Что | Где |
|---|---|
| Сон, работа, финансы, активность, вес, зарядка, идеи, списки аниме и фильмов | `LifeOS/Data/life.json` |
| Загруженные обложки | `LifeOS/Covers/` |
| Файлы и картинки идей | `LifeOS/Ideas/Files/` |
| Привычки, настроение, рефлексия | заметка дня |
| Люди | заметки с `type: person` (`category`, `birthday`) |
| Проекты | `type: work`, `study` или `research` (`status`, `deadline`) |
| Цели | `type: goal`, `progress: 0–100` |
| Встречи | `type: meeting` (`date`, `time`) |

Задачи пишутся в формате, совместимом с плагином Tasks (`#daily`, `#main`, `#meeting`, `#rolodex`, `#travel`, `#work`, `#study`, `#research`).

## Опциональные плагины

Life OS работает и без них, но хорошо сочетается с **Calendar**, **Tasks**, **Templater**, **Dataview**, **Remotely Save** и **Obsidian Git** (для синхронизации хранилища с GitHub или GitLab).

## Известные ограничения
- Мало тестировался в реальном Obsidian
- Повторяющиеся события ICS не разворачиваются
- Бот Telegram работает только пока Obsidian запущен
- Оценки и серии Shikimori только читаются
- Формат API CUB требует проверки на реальном аккаунте
- Обложки при импорте экспорта Shikimori подставляются по id аниме и могут не загрузиться: тогда задай обложку вручную
- Рекомендации в «Спорте» общие и не заменяют консультацию врача или тренера

## Разработка
Сборка не нужна: плагин написан на чистом JavaScript (`main.js`), стили в `styles.css`. Для разработки скопируй репозиторий в `.obsidian/plugins/life-os/` и перезагружай плагин после правок.
